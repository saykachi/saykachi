### about

I build fast, reliable cross-platform applications and web services — from interface design to server-side logic. Clean architecture and clean code come first.

- desktop apps with **Tauri** and **Rust**, native speed without the bloat
- responsive web apps on **React**, **Vue** and **Next.js**
- APIs with **Node.js / Express** and **Rust**, backed by **MongoDB**
